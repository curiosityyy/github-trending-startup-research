# Startup Radar

把产品发布、技术社区、投资主题、GitHub 趋势和真实用户差评交叉验证，寻找值得测试的创业机会。

## Website

本地开发：

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

当前机器使用只监听回环地址的静态服务，并由 Caddy 在 `/startup-radar/` 路径对外转发。部署文件位于 [`deploy/`](deploy/)。
